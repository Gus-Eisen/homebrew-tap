# Gus-Eisen/homebrew-tap

Homebrew formulae for my tools.

```sh
brew install gus-eisen/tap/ringer
```

| Formula | Description |
|---------|-------------|
| [ringer](https://github.com/Gus-Eisen/ringer) | Terminal countdown timer that warns you when you won't hear the alarm |

`Formula/ringer.rb` is updated automatically when a new ringer release is published.
